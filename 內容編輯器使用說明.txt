一水千田・時光水滴 v20｜內容編輯器使用說明
================================================

這一版多了一個 editor.html（內容編輯器）。不用改程式，就能替換台詞、題目、史料、結局、圖片和 3D 模型。
改的時候右邊會即時預覽，改好按「發布」就會自動更新到 GitHub 網站。

【第一次部署（只要做一次）】
1. 把這個資料夾裡的所有檔案（含 font 資料夾）上傳到 GitHub 儲存庫 yishui-qiantian，蓋掉舊檔。
2. 等 1～2 分鐘，打開 https://p77937793-alt.github.io/yishui-qiantian/editor.html

【申請 GitHub 權杖（只要做一次）】
GitHub 右上角頭像 ▸ Settings ▸ Developer settings ▸ Personal access tokens ▸ Fine-grained tokens ▸ Generate new token
・Repository access：Only select repositories → 選 yishui-qiantian
・Permissions ▸ Repository permissions ▸ Contents：Read and write（想看部署狀態可再加 Pages：Read-only）
・建立後複製權杖（github_pat_ 開頭），只會顯示一次
權杖等於這個儲存庫的寫入鑰匙：不要貼到群組、不要寫進檔案；公用電腦不要勾「記住權杖」。

【平常怎麼改】
1. 打開 editor.html。左邊選分頁修改，右邊就是遊戲預覽：
   📍 站點與台詞：站名、人物、台詞（每條路線各一份）、史料卡、照片
   ⚖️ 分歧題目：兩個關鍵分歧的題目、選項、優缺點、提示
   🏁 結局：四種結局的標題、條列與依據
   🔎 原因與對照：結局的因果鏈、對照圖 ①–⑦ 在各路線的狀態文字
   📚 來源：新增、修改、刪除參考來源（史料卡可勾選出處）
   🎮 小遊戲與開場：小遊戲標題與玩法說明、開場說明
   🖼️ 圖片：換掉史料照片或地面平面圖
   🧊 3D 模型：上傳 .glb，替換取水口、埤塘、田、辨天池、人物、水滴等 27 個模型，並用滑桿調整大小、方向、位置
2. 上面的「第1區…第5區」「結局A～D」可以直接跳去預覽。
3. 修改會自動存成草稿（同一台電腦、同一個瀏覽器）；關掉再打開會問你要不要接著編輯。
4. 到「🚀 檢查與發布」：先看檢查結果，填帳號 p77937793-alt、儲存庫 yishui-qiantian、權杖，按「測試連線」，再按「發布」。
5. 發布後 1～2 分鐘網站就會更新；手機若還看到舊的，重新整理一次。

【3D 模型怎麼做】
Blender：檔案 ▸ 匯出 ▸ glTF 2.0，格式選「glTF 二進位（.glb）」，不要勾 Draco 壓縮。
支援網格、頂點色、材質顏色；不支援貼圖、動畫、骨架。上傳後會自動對齊原本模型的位置和大小。

【注意】
・站點的數量、順序、小遊戲的規則與數字是程式的一部分，編輯器不能改；需要的話請找 Claude。
・兩個人同時改時，後發布的人會看到「網站內容被別人更新過」的提醒，避免互相覆蓋。
・新打的字如果不在內建字型裡，網頁會另外下載完整字型（font/huninn-full.woff，約 2.9 MB）；離線時改用手機的系統字型。
・用檔案總管直接打開 editor.html 也能編輯和發布，但不會讀到網站上目前的 content.json，也無法勾選「同時上傳遊戲程式」。建議用網站上的 editor.html。
